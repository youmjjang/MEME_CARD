# T05 · 대화가 끊겨도 이어지는 프로젝트 — 고정 계획

## 작은 개선 한 개

과제 3 `MemeLab · 짤·카드 스튜디오`에 **문구 위치 잠금** 기능을 추가한다. 잠그면 문구 X/Y 입력과 캔버스 문구 드래그가 막히지만 배경 위치와 글자 스타일 편집은 계속 가능해야 한다. 저장한 템플릿을 불러오면 잠금 상태도 함께 복원되어야 한다.

## 공통 사용 상한

- 시간 상한: **45분**
- 요청·호출 수 상한: **12회**
- AI A와 AI B에 똑같이 적용한다.
- 무료 한도를 소진하지 않고 상한 전에 계획한 상태에서 멈춘다.

## 두 AI에 줄 같은 최초 요청

> 시작 저장소와 이 고정 계획만 보고 작업하세요. 작은 개선 목표는 “문구 위치 잠금” 기능입니다. 아래 고정 검사 T05-01~T05-10을 삭제·완화하거나 입력·기대값을 변경하지 말고 모두 통과시키세요. 기존 기능을 유지하고, 검사 실행 결과와 FAIL이 하나 이상인 실행 회차 수를 기록하세요. 시간 45분과 요청·호출 12회 상한을 넘기지 마세요.

## 작업 전 고정 검사 10개

| ID | 입력 / 행동 | 관찰 가능한 기대 결과 |
| --- | --- | --- |
| T05-01 | 편집 화면을 처음 연다. | **문구 위치 잠금** 체크박스가 보이고 기본값은 해제 상태다. |
| T05-02 | 문구 위치 잠금 체크박스를 켠다. | 체크박스가 선택되고 화면에 **문구 위치 잠김** 상태 문구가 보인다. |
| T05-03 | 문구 X=30%, Y=40%에서 잠금을 켠다. | 문구 X/Y 슬라이더가 비활성화되고 표시값은 30/40으로 유지된다. |
| T05-04 | 잠긴 X/Y 슬라이더에 키보드 입력을 시도한다. | X/Y 값이 바뀌지 않는다. |
| T05-05 | 1:1 화면에서 문구를 50/50에 두고 잠근 뒤 캔버스 문구를 드래그한다. | 문구 X/Y가 50/50 그대로다. |
| T05-06 | 문구 X=25%, Y=35%로 잠근 뒤 화면비를 4:5로 바꾼다. | 잠금 상태와 문구 X/Y 25/35가 유지된다. |
| T05-07 | 문구를 잠근 뒤 배경 X/Y를 20/80으로 바꾼다. | 배경 슬라이더는 활성 상태이고 표시값이 20/80으로 바뀐다. |
| T05-08 | 문구를 잠근 뒤 글자 크기를 72px, 색상을 #ff0000으로 바꾼다. | 잠금은 유지되고 크기 72px와 색상 #ff0000이 적용된다. |
| T05-09 | 잠금을 해제한 뒤 문구 X 슬라이더를 65%로 바꾼다. | X/Y 슬라이더가 다시 활성화되고 문구 X가 65%로 바뀐다. |
| T05-10 | 문구 X=30%, Y=40%와 잠금 상태를 템플릿으로 저장하고, 잠금을 해제해 위치를 바꾼 뒤 그 템플릿을 불러온다. | 문구 X/Y가 30/40으로 복원되고 잠금 체크·상태 문구·비활성 슬라이더도 함께 복원된다. |

## 오류 회차 계산 규칙

고정 검사 10개를 전부 실행한 것을 한 회차로 보고, 한 개 이상 FAIL이 있으면 오류 회차 1회로 센다.

## 고정 작업 순서

1. AI A 시작
2. AI A 종료·인수인계
3. AI B 시작
4. AI B 종료

검사 ID·입력·기대값과 공통 상한은 이 커밋 이후 변경하지 않는다.
