# T05 · 대화가 끊겨도 이어지는 프로젝트 — 고정 계획

## 작은 개선
과제 3 `MemeLab · 짤·카드 스튜디오`에 **문구 위치를 한 번에 캔버스 정중앙(50%, 50%)으로 보내는 “문구 가운데로” 버튼**을 추가한다.

기존의 배경 “가운데로” 기능, 드래그, 화면비, 템플릿, 이미지 저장 동작은 바꾸지 않는다.

## 공통 사용 상한
- 시간 상한: **45분**
- 요청 상한: **12회**
- AI A와 AI B에 동일하게 적용한다.
- 상한은 무료 한도를 소진하기 위한 목표가 아니라, 그 전에 멈추기 위한 최대치다.

## 두 AI에 줄 같은 최초 요청
> 시작 저장소와 이 문서만 보고 작업하세요. 작은 개선 목표는 “문구 가운데로” 버튼 추가입니다. 아래 고정 검사 T05-01~T05-10을 변경하지 말고 모두 통과시키세요. 기존 기능은 유지하세요. 작업 중 검사 실행 결과와 실패 회차를 기록하세요. 정해진 상한(45분, 요청 12회)을 넘기지 마세요.

## 고정 검사 10개
| ID | 입력 / 행동 | 관찰 가능한 기대 결과 |
| --- | --- | --- |
| T05-01 | 편집 화면을 연다. | 문구 위치 조정 영역에 **“문구 가운데로”** 버튼이 보인다. |
| T05-02 | 문구 X=10%, Y=20%로 바꾼 뒤 “문구 가운데로”를 누른다. | 문구 X와 Y 표시값이 각각 **50%, 50%**가 된다. |
| T05-03 | 1:1 비율에서 문구를 임의 위치로 드래그한 뒤 버튼을 누른다. | 문구가 1:1 캔버스 정중앙으로 이동하고 X/Y가 50/50이다. |
| T05-04 | 4:5 비율에서 문구를 임의 위치로 드래그한 뒤 버튼을 누른다. | 문구가 4:5 캔버스 정중앙으로 이동하고 X/Y가 50/50이다. |
| T05-05 | 9:16 비율에서 문구를 임의 위치로 드래그한 뒤 버튼을 누른다. | 문구가 9:16 캔버스 정중앙으로 이동하고 X/Y가 50/50이다. |
| T05-06 | 배경 위치를 X=15%, Y=85%로 바꾼 뒤 “문구 가운데로”를 누른다. | 배경 X/Y는 **15/85 그대로**이고 문구만 50/50이 된다. |
| T05-07 | 문구 글자 크기·색·정렬을 바꾼 뒤 버튼을 누른다. | 글자 스타일 값은 유지되고 위치만 50/50으로 바뀐다. |
| T05-08 | 버튼으로 문구를 50/50으로 만든 뒤 템플릿을 저장하고 다시 불러온다. | 불러온 템플릿의 문구 위치가 50/50으로 복원된다. |
| T05-09 | 버튼으로 문구를 50/50으로 만든 뒤 PNG/JPEG 저장을 실행한다. | 오류 없이 저장되고, 저장 결과의 문구 위치가 미리보기의 중앙 위치와 일치한다. |
| T05-10 | 문구를 0/0 및 100/100 경계 위치로 각각 옮긴 뒤 버튼을 누른다. | 두 경우 모두 오류 없이 정확히 50/50으로 돌아온다. |

## 오류 회차 계산 규칙
고정 검사 10개를 한 번 전부 실행한 것을 1회차로 본다. 그 회차에서 **하나라도 FAIL이면 오류 1회**로 센다.
