# 공개 안전 확인

2026-09-11 기준 공개할 화면·소스·문서·샘플을 검사했습니다.

- 샘플 이미지: 외부 원본 없이 이 프로젝트의 Canvas 코드로 생성한 도형 그래픽입니다.
- 모든 공개 PNG/JPEG를 실제로 디코딩하고 EXIF GPS 및 위치 관련 메타데이터 키를 확인했습니다. 검출 0건입니다.
- 공개 이미지와 화면에는 실제 인물·연락처·주소가 없으며, 배포 파일의 토큰·비밀키 원문 검사 결과 0건입니다.
- 업로드 이미지는 브라우저에서 Canvas로 다시 생성하며 원본 메타데이터를 템플릿/다운로드로 복사하지 않습니다.
- 외부 API 호출, 분석 추적기, 광고 SDK, 비밀번호/키가 포함된 설정 파일이 없습니다.
- 개인 이메일을 커밋에 넣지 않고 GitHub noreply 주소를 사용합니다. 공개 저장소 사용자명은 소스 주소에 필요한 계정 식별자입니다.

범위와 이미지별 크기·해시는 [안전 점검 원본](../evidence/safety-audit.json)에 기록했습니다. 사용자가 나중에 추가하는 사진·문구의 내용과 사용 권한까지 자동 판정하는 기능은 없습니다.
